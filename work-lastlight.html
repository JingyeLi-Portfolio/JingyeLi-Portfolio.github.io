Last Light

第一章《最后的微光》。停电的安全屋、一桶燃油、一条穿过住宅区的路—— 这一章只做一件事：让玩家在没有任务箭头的情况下，靠空间自己读出「我该往哪走」。

任务目标 · Objective

Restore Power — 恢复供电

Haven House 的备用发电机已经停止工作。玩家必须前往 Miller's Fuel 搜寻燃油， 避开住宅区的感染者，并把燃油带回安全屋。当发电机重新启动，屋内一盏昏暗的灯亮起。 远处的水塔依然沉在黑暗里——它提醒玩家，恢复一栋房子的供电，只是第一步。

01

项目概述与实现范围

这是个人的关卡设计练习。下面写清楚哪些已经在 Unity 里跑通、哪些还停在纸面—— 把边界说清楚，比把话说满更有用。

做这张图的时候我给自己定的约束是：不放引导箭头，不放 UI 任务marker。 玩家能不能自己找到加油站，取决于路网本身写得是否清楚——这正是我想验证的部分。 所以这一章的核心是「可读性」：让空间结构本身承担导航。

已在 Unity 中实现

  • 小镇街区白盒：安全屋、住宅区、后巷、加油站主体量
  • 探索动线与 POI 空间关系（可按 02 的路线实际走通）
  • 燃油拾取 → 返回安全屋 → 发电机重启的主线流程
  • 基础感染者巡逻与感知（视听范围，可触发追击）
  • 灯光作为反馈：发电机启动后的屋内照明变化

仍在设计规划中

  • 资源随机刷新表与掉落权重（当前为手动摆放）
  • 第二章「水塔」区域的接驳设计
  • 完整的制作 / 建造系统与数值平衡
  • 美术层：目前只到白盒 + 临时材质

03

玩家流程与路线设计

从安全屋到加油站，我留了三条走得通的路。切换选项卡，上方平面图会同步显示对应路线与决策点。

路线 A · 主街直行

路程最长 · 暴露最高 · 遭遇密度中

沿主街一路向东。这条路几乎不需要「找」——所以它承担教学：先在认知负担最低的情况下， 把街区的方向和尺度讲清楚。选它的玩家往往是因为看见了远处加油站的顶棚轮廓。

  1. D1 出门向左还是向右：右侧主街尽端能看到加油站顶棚剪影，完成第一次空间定向
  2. D2 杂货店转角停不停：转角天然减速，用一次试错教会玩家「看到街角就值得进去」
  3. D3 废弃路障怎么绕：通行宽度被收到一侧，脚步与视线同时被推向预设方向
  4. D4 加油站前场怎么进：开阔暴露窗口，必须判断走正门还是绕后门

回程建议原路返回：安全，但几乎拿不到额外资源。

路线 B · 后巷潜行

路程最短 · 视野受限 · 撤退空间最小

沿住宅北侧绕进后巷，从加油站后门进。它的存在是为了给「已经熟悉地形的玩家」一条更聪明的选择—— 代价是几乎没有容错：被发现时，后巷从捷径变成交火现场。

  1. D1 要不要绕去北侧：入口不明显，第一次玩的玩家大概率错过
  2. D2 后巷中段停不停：唯一的垃圾桶半掩体，是这条路上唯一的喘息点
  3. D3 住宅区边缘抢不抢：顺手资源近在眼前，但感染者密度也在这里上升
  4. D4 后门进还是绕正门：后门几乎无声，但一旦被发现，退路只有来时那条窄巷

设计时反复确认的标准：瓶颈点可以难受，但必须有可视被告知的出口。

路线 C · 街背慢搜

资源收益最高 · 耗时最长 · 遭遇次数最多

贴着住宅区外侧、穿过杂货店后院再到加油站。这是给「第二次、第三次重玩」的玩家准备的路线： 第一次通关的人不知道巷子里有东西，知道的人才会愿意多花时间绕。

  1. D1 进不进第一栋住宅：门口杂物暗示可搜，进去则失去退路视野
  2. D2 带不带走这份物资：背包空间有限，这是全章第一道资源取舍题
  3. D3 弹药够不够走完：慢搜路线的真实瓶颈不是路线，而是消耗品
  4. D4 继续搜还是见好就收：拿上一桶燃油之后，回程的每一步都在算收益

这条路撑起了重复可玩性：同一个关卡，第二轮才是完整内容。

05

资源与遭遇编排

资源不是随机撒的，威胁也不是。下表写的是每个 POI「为什么放这些东西」—— 让每一次弯腰捡拾，都对应一次真实的取舍。

POI 资源投放 遭遇编排 玩家要做的取舍
P01 Haven House 基础物资、主线目标（发电机） 无敌人 出门前要不要多带一个弹匣
P02 Corner Store 食物、零件、少量弹药 1–2 只游荡感染者 低风险收益，用来教搜索规则
P03 Residential 医疗、工具、弹药 密度最高，室内潜伏 高收益换高消耗，能否走完回程
P04 Back Alley 零散物资 少但致命，退路被切断 抄近道是否值得赌一次被发现
P05 Roadblock 车体物资 无强制遭遇 暴露在路中央捡东西值不值
P06 Miller's Fuel 燃油（主线）、补给 中密度，前场开阔、室内掩护 先清场还是拿到就跑
